**ДЗ 35. Завдання: Телефонна книга на JavaScript**

Опис:

Створити простий односторінковий додаток для збереження контактів у браузері.

Що потрібно реалізувати:

1. Додавання контакту

   - Поля: ім’я, прізвище, телефон (+380XXXXXXXXX)

   - Збереження у localStorage

2. Відображення списку контактів

   - Вивести всі збережені контакти у вигляді таблиці або карток

3. Видалення контакту

   - Кнопка “Видалити” поруч із кожним контактом

4. Пошук

   - Поле для пошуку за ім’ям або телефоном (без урахування регістру)

Технічні вимоги:

- JavaScript (ES6+), HTML, CSS

- Модульна структура (наприклад, окремі файли чи класи для роботи з localStorage та для оновлення DOM)

- Ніяких сторонніх бібліотек

Як запускати:

1. Відкрити index.html у браузері.

2. Працювати з формою додавання та списком контактів.

Критерії приймання:

- Контакти додаються та відображаються правильно

- Видалення працює без помилок

- Пошук видає лише ті записи, що відповідають запиту
